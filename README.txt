# Feuerwehr-Website – Version 1

## Starten

1. Entpacke den Ordner.
2. Öffne `index.html` im Browser.
3. Ändere HTML in `index.html`.
4. Ändere Design und Farben in `style.css`.
5. Ändere Verhalten in `script.js`.

## Wichtig

Diese Version ist bewusst noch eine reine Frontend-Version.
Termine und Nachrichten sind momentan Beispielinhalte.

Im nächsten Schritt kann daraus eine PHP/MySQL-Version werden:
- Login
- Admin-Dashboard
- Termine erstellen/bearbeiten/löschen
- Nachrichten verwalten
- Bilder hochladen
- Einsatzberichte verwalten
